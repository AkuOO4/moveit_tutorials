# robot_state

This package contains tutorials on robot state representation and manipulation using MoveIt! for the Panda robot in ROS 2.

## Contents
- Example C++ node: `src/robot_state_tutorial.cpp`
- Launch file: `launch/robot_state_tutorial.launch.py`

## Usage
Launch the robot state tutorial with:
```bash
ros2 launch robot_state robot_state_tutorial.launch.py
```

## Purpose
- Understand robot state concepts
- Manipulate and query robot states programmatically
