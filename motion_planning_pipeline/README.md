# motion_planning_pipeline

This package demonstrates the MoveIt! motion planning pipeline for the Panda robot in ROS 2.

## Contents
- Example C++ node: `src/planning_pipeline.cpp`
- Launch file: `launch/planning_pipeline.launch.py`
- Pipeline configuration and usage

## Usage
Launch the planning pipeline demo with:
```bash
ros2 launch motion_planning_pipeline planning_pipeline.launch.py
```

## Purpose
- Explore the MoveIt! planning pipeline
- Learn how to configure and use different planners
