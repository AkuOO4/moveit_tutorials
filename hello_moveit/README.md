# hello_moveit

This package provides basic MoveIt! usage and path planning examples for the Franka Emika Panda robot in ROS 2.

## Contents
- Example C++ node: `src/hello_moveit.cpp`
- Basic path planning demonstrations
- Entry-level MoveIt! API usage

## Usage
Launch the example with:
```bash
ros2 launch hello_moveit <launch_file>.py
```

## Purpose
- Learn MoveIt! basics
- Understand simple motion planning concepts
